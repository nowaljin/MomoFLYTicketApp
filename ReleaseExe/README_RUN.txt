Double-click AirlineTicketReservationSystem.exe to start the application.

If Windows asks for permission, choose Run.
The app uses MongoDB Atlas and the connection string is already filled in.
Click Initialize DB inside the app to create/reset the sample data.

If you see a server selection timeout:
1. Open MongoDB Atlas.
2. Go to Network Access.
3. Add your current IP address, or for school/demo only add 0.0.0.0/0.
4. Make sure the cluster is not paused.
5. Run the exe again and click Test.
